# 🧊 Plateful-Ai [Live Link]
Plateful-Ai is an **AI-powered recipe discovery app** designed to help users make the most of what’s already in their fridge.  
Simply enter your available ingredients, and Plateful-Ai suggests smart, creative recipes — saving time, reducing waste, and making cooking fun again!

---

## ✨ Features

- 🧠 **AI Chatbot Integration** – Interact with an intelligent chatbot powered by the **Gemini API** to get personalized recipe ideas, cooking tips, and ingredient substitutions.  
- 🥗 **Smart Recipe Finder** – Instantly generates recipes based on ingredients you already have using the **Spoonacular API**.  
- 🛒 **Ingredient Management** – Easily add remove ingredients in your fridge favorite list.  
- ⚡ **Modern UI/UX** – Built with **TailwindCSS** and **DaisyUI** for a responsive, smooth, and aesthetic experience.  
- 🔄 **State Management with Redux** – Efficient global state handling for ingredients, recipes, and chatbot conversations.  
- 💬 **Interactive Experience** – Combines AI + React to provide real-time recipe suggestions and conversational cooking assistance.  

---

## 🛠️ Tech Stack

- **Frontend:** React.js  
- **State Management:** Redux Toolkit  
- **Styling:** TailwindCSS, DaisyUI  
- **AI Integration:** Gemini API  
- **Recipe Data Source:** Spoonacular API  

---

## 🧠 How the AI Chatbot Works

The integrated **AI Chatbot**, powered by the **Gemini API**, brings intelligent interaction to your cooking experience.  

- 🍳 **Conversational Cooking:** Users can chat with the bot to get recipe suggestions based on ingredients they currently have.  
- 🧂 **Smart Ingredient Handling:** The chatbot analyzes input ingredients and recommends possible dishes or substitutes.  
- 🥗 **Personalized Suggestions:** It tailors recipe ideas according to user preferences or dietary restrictions.  
- ⚡ **Real-Time Responses:** Gemini API processes messages instantly to create a smooth, interactive experience.  
- 🍽️ **Recipe Integration:** The chatbot fetches real recipes from the **Spoonacular API**, providing users with detailed cooking instructions and ingredient lists.  

> The chatbot acts like your personal kitchen assistant — available anytime to help you cook smarter and reduce food waste.
